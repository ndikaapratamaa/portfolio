# 🚀 Personal Portfolio Website - Refactored & Enhanced

Website portofolio pribadi yang telah **dirombak total** dan ditingkatkan dari segi struktur kode, tampilan antarmuka (UI/UX), serta keterbacaan untuk menyajikan profil, keahlian, dan proyek secara lebih profesional.

---

## 🌟 Pembaharuan & Fitur Utama

- **🎨 Modern UI/UX Refactor**: Penyesuaian tata letak, skema warna dinamis, dan efek visual yang lebih halus.
- **📱 Responsive & Adaptive Layout**: Optimal diakses dari berbagai ukuran layar (Desktop, Tablet, & Mobile).
- **⚡ Clean Code Structure**: Refactoring komponen HTML & CSS agar lebih terstruktur, ringkas, dan mudah dirawat (*maintainable*).
- **📂 Interactive Projects & Skills Section**: Menampilkan daftar keahlian dan karya dengan tampilan kartu (*card layout*) yang rapi.
- **🌙 Dark Mode Support**: Efek tema gelap yang nyaman di mata.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** – Struktur halaman web yang semantik
- **CSS3 / Sass** – Styling, animasi, dan tata letak responsif
- **JavaScript (ES6+)** – Interaktivitas elemen dan manipulasi DOM
